# DeForTrack Landing Page

Website informasi publik untuk DeforTrack, sistem monitoring deforestasi dan
pengelolaan lahan berbasis drone, laporan petani, dan dashboard peran.

## Tech Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- lucide-react

## Menjalankan Proyek

```bash
npm install
npm run dev
```

Buka `http://localhost:3000` di browser.

## Struktur Aset

- `public/images/defortrack-hero.png` untuk visual hero.
- `public/team/` untuk foto anggota tim.
- `public/downloads/defortrack.apk` untuk placeholder file APK.

## Script

```bash
npm run lint
npm run build
```
